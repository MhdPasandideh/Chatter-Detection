# Unsupervised Chatter Detection in CNC Machining (AE + DBSCAN)

Reference implementation and data for the paper:

> **An Unsupervised Chatter Detection Method Based on AE and DBSCAN Clustering Utilizing Internal CNC Machine Signals**
> Mohammad Pasandidehpoor, João Mendes-Moreira, João Manuel R. S. Tavares
> FEUP / LIAAD-INESC TEC, University of Porto
> *Machines* (MDPI), 2026. Manuscript ID: machines-4572445.

This repository contains:

- The full Python pipeline: preprocessing, autoencoder training, adaptive DBSCAN clustering, and evaluation.
- Figure-generation scripts for every figure in the manuscript.
- Instructions for obtaining the **primary internal-CNC dataset** (recorded by the authors) and the **external NASA milling-wear dataset** used as an independent validation set.
